### `src/evaluation`

This folder contains the scripts for evaluating the performance of RAG (Retrieval-Augmented Generation) pipelines and their components. It uses the **Ragas** framework to automatically assess key metrics, providing a quantitative measure of model quality.

---

### **Overview**

The evaluation pipeline is designed to perform two main types of assessments:

1.  **QA Test Set Evaluation (`eval_qa_pipeline.py`):** Assesses the quality of the synthetic question-answer pairs generated by the `src/generation` pipeline. This step is crucial for validating that the generated data is a high-quality "gold standard" for later evaluation.
2.  **RAG Model Evaluation (`eval_rag_pipeline.py`):** Compares the responses of different RAG models (e.g., Gemini vs. GPT) against a reference, measuring their performance on metrics like correctness, semantic similarity, and context precision.

---

### **Key Scripts**

- `eval_rag_pipeline.py`: The primary script for evaluating RAG models. It loads a merged dataset (from `src/utils/fusion_data.py`), applies a suite of Ragas metrics to multiple models, and saves the comprehensive results to a CSV and JSONL file for detailed analysis.
- `eval_qa_pipeline.py`: This script focuses on the quality of the synthetically generated data itself. It uses Ragas metrics to score the question-answer pairs and their contexts, including a custom metric for **question quality**. This ensures that the generated test data is reliable before using it to evaluate other models.

---

### **Metrics Used**

The evaluation scripts use a variety of Ragas metrics to provide a nuanced view of performance:

- **`Faithfulness`**: Measures if the generated answer is grounded in the provided context.
- **`ResponseRelevancy`**: Assesses if the generated answer is relevant to the user's question.
- **`FactualCorrectness`**: Checks if the generated answer is factually correct compared to the reference.
- **`SemanticSimilarity`**: Compares the semantic similarity between the model's response and the reference answer.
- **`NonLLMContextPrecisionWithReference`**: Evaluates how relevant the retrieved contexts are to the reference answer, without relying on an LLM for the judgment.

---

### **Usage**

To run the evaluations, simply execute the desired script:

```bash
# To evaluate the quality of the generated QA data:
python eval_qa_pipeline.py

# To evaluate the RAG models (after running fusion_data.py):
python eval_rag_pipeline.py
```

Ensure the necessary data files and environment variables are in place before running.
